## Tools used

The team owner reports using **ChatGPT, Codex, Claude Code, OpenCode, Cursor and DeepSeek**.
The record verifies Codex assistance with implementation, debugging, data-pipeline code,
source analysis, test execution, documentation and submission preparation. The exact division
of work, underlying model versions and prompts used in the other tools has not been independently
recorded; this disclosure does not invent those details. Team members retain responsibility

## Code, text and data

Code and documentation were produced with AI assistance and checked using the repository's
unit, backend, data reproduction and browser suites. AI-assisted ingestion code parses NASA
originals; the measurements are NASA source data. No missing measurement, outcome, safety
probability, citation or model-quality result is synthesized. Curated report summaries are
paraphrases linked to specific source pages. Retrieved text is evidence, not executable instructions.

At runtime the default assistant is deterministic. Optional server-enabled OpenAI interpretation
is guarded by evidence-ID checks and fallback. No authenticated live model or speech-quality
validation was completed. Do not describe mock responses or the default retrieval mode as live
model inference. Machine-readable disclosure: [public/ai-disclosure.json](public/ai-disclosure.json).

## Images, video and sound

Repository QA screenshots and recordings are genuine browser captures, not generated depictions
of NASA experiments. Original SVG stars, rocket and interface shapes are code-based conceptual
illustrations made with AI assistance; they are not NASA branding, mission identifiers, hardware
models or experimental observations. No raster image/video generation tool is established in
this work record. Any subsequently generated bitmap/video must be visibly identified before use.

The owner cannot confirm the creator, generator or reuse rights of the five legacy narration
MP3s. They are excluded from the current repository tree and app release. Local originals are
preserved outside the tracked/public asset tree for provenance review, with hashes in
[asset provenance](docs/submission/assets.json). The internal explainer runs with captions and
no audio requests. Do not restore or use these clips in a submission/demo until their source,
rights and any required AI acknowledgment in text/metadata have been established. This says
nothing about live voice input/output, which remains a separate optional, unverified capability.
