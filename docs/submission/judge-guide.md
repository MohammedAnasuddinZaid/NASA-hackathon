# Judge's walkthrough

FIRETRACE by The Code Blooded. Start with the root README to run the app. No credentials,
model download or external API payment is needed for the core evidence journey. The repository
is the final project link; localhost addresses work only on the machine running the app.

1. **Evidence Atlas:** search `BASS2-B1`, open the row and inspect 22.2% initial oxygen.
   Open the measurement ledger and original CSV row 2. Pressure remains unknown. Try a quality
   filter and inspect a suspect record such as `BASS2-P22b`; flags are preserved.
2. **Compare:** add BASS-II and Saffire-I records. Read material, geometry, thickness and flow
   differences, the missing pressure/gravity disclosures and comparability blockers. These
   experiments are not interchangeable safety evidence.
3. **Gap Planner:** set a cabin scenario and inspect candidate correspondence/missingness.
   Change a condition, review the heuristic ordering and download the gap plan. No relevance
   score represents a probability of safety.
4. **Evidence Assistant:** ask `What oxygen did BASS2-B1 report?`, then `What pressure was
   BASS-II run at?` and `Is PMMA safe in a lunar cabin?`. Inspect citations and abstention.
   The default route is deterministic; unconfigured external-model capability is not a live demo.
5. **Research Library:** open it from Evidence Atlas. Inspect BASS-II and FLEX findings, source
   pages and solid-fuel/liquid-droplet labels. FLEX report findings are not normalized test rows.
6. **Evidence basket / Notebook / Exports:** select records, navigate between pages, generate a
   concise brief, inspect its source list and download CSV/JSON/Markdown/HTML. Use a notebook,
   graph or verification page to follow the evidence relationships. Reload to check persistence.
7. **Coverage / Integrity / System Health:** inspect gaps, actual integrity checks and capability
   status. Failure/fallback messages distinguish API, bundled and optional model availability.

Four main pages have visible tabs; Research/Workspace dropdowns and the compact grouped Menu
provide access to all 17 pages. Pause decorative motion or use
reduced-motion settings. The internal 45-second captioned explainer is an application feature,
not the separate event submission demo.
